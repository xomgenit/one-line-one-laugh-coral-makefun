A program that writes one funny line to `entry.txt` for make.fun's "One Line, One Laugh" bounty — a single self-contained joke, judged pairwise by an AI comedy editor. The line escalates in three beats: a reasonable request, two very human evasions, and a meeting scheduled about it.

## Run it

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
